# Function recovery

## Required inputs

- exact target or queued question;
- ROM identity;
- emulator identity when runtime evidence is used;
- current checkpoint;
- evidence and stopping standards.

## Procedure

1. Create function ID.
2. Confirm address domain and ROM version.
3. Find candidate boundaries.
4. Trace entries and exits.
5. Catalog reads/writes/calls.
6. Vary inputs.
7. Write pseudocode.
8. Test alternatives.
9. Assign confidence and name.

## Required outputs

- updated canonical record;
- raw evidence references and hashes;
- confidence and alternatives;
- relationship/index updates;
- exact next action;
- checkpoint when the unit stops.
