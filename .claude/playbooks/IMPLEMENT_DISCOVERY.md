# Go implementation

## Required inputs

- exact target or queued question;
- ROM identity;
- emulator identity when runtime evidence is used;
- current checkpoint;
- evidence and stopping standards.

## Procedure

1. Read approved discovery.
2. Define narrow package/API.
3. Implement verified behavior.
4. Add unit tests.
5. Add fuzz/golden tests.
6. Update docs.
7. Run gates.
8. Link commit to discovery.

## Required outputs

- updated canonical record;
- raw evidence references and hashes;
- confidence and alternatives;
- relationship/index updates;
- exact next action;
- checkpoint when the unit stops.
