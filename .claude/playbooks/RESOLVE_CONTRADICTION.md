# Contradiction resolution

## Required inputs

- exact target or queued question;
- ROM identity;
- emulator identity when runtime evidence is used;
- current checkpoint;
- evidence and stopping standards.

## Procedure

1. Freeze dependent work.
2. List claims.
3. List exact evidence.
4. Check ROM/state/address-space differences.
5. Design discriminator.
6. Run experiment.
7. Publish resolution and supersession links.

## Required outputs

- updated canonical record;
- raw evidence references and hashes;
- confidence and alternatives;
- relationship/index updates;
- exact next action;
- checkpoint when the unit stops.
