# Project audit

## Required inputs

- exact target or queued question;
- ROM identity;
- emulator identity when runtime evidence is used;
- current checkpoint;
- evidence and stopping standards.

## Procedure

1. Inventory canonical sources.
2. Find unsupported facts.
3. Find address ambiguity.
4. Find stale dashboards.
5. Find provenance gaps.
6. Review package graph.
7. Review tests.
8. Report prioritized defects.

## Required outputs

- updated canonical record;
- raw evidence references and hashes;
- confidence and alternatives;
- relationship/index updates;
- exact next action;
- checkpoint when the unit stops.
