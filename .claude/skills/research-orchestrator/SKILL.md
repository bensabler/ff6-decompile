# Research Orchestrator

Read the latest checkpoint, current focus, queue, milestones, blockers, and contradictions.

Score candidate work by:
- information gain;
- number of dependencies unblocked;
- reproducibility;
- confidence improvement;
- cost and risk;
- relevance to the active milestone.

Select one bounded unit. Write its experiment plan before operating Mesen. Delegate specialists only when their outputs can be integrated into the same unit. Finish by updating evidence, indexes, queue, graph, and checkpoint.
